# Grovix — Intelligent Solutions Powered by AI

A 1:1 responsive replica of the Grovix website template with dynamic animations, interactive cart, pricing, bento feature grid, and subpages.

## Pages Included
- **Home** (`/`)
- **Features** (`/features`)
- **About** (`/about`)
- **Pricing** (`/pricing`)
- **Blog** (`/blog`)
- **Contact** (`/contact`)

## Features
- Complete responsive layouts for desktop, tablet, and mobile
- Interactive Cart drawer with plan selection and real-time counter
- FAQ Accordions with animated transitions
- Scroll-based micro-interactions and 3D transforms
- Company marquee and bento dashboard visualizations

## Running Locally
You can serve the static files using any local server, for example:
```bash
npx http-server . -p 3000 -c-1
```
Open [http://localhost:3000](http://localhost:3000) in your browser.
